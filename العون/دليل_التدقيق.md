# دليل تعليم الفواتير المدقّقة — محلات العون

> الحقل المستعمل: **`ref`** — اسمه بأودو **«الرقم المرجعي»**، وبنموذج فاتورة العميل بيظهر باسم **«رقم العميل المرجعي»**.
> **قالب الفاتورة ما بيطبعه إطلاقاً**، وقالب الكشف بيقصّ العلامة — فالزبون ما بيشوف إشي.

---

## ⚡ الأسرع — قائمتين جاهزتين بأودو (بتشتغل على الموبايل)

```
المحاسبة  →  العملاء  →  ⏳ فواتير للتدقيق      ← كل اللي لسا ما اندقق
المحاسبة  →  العملاء  →  ✓ فواتير مدقّقة        ← كل اللي دقّقته
```
كبسة وحدة. ما بدها أعمدة ولا بحث ولا تتذكر أي إشي.

---

## ١) كيف تعلّم فاتورة — **زر جاهز** ⭐

```
المحاسبة → العملاء → «فواتير للتدقيق»
  ↓
✅ علّم مربّع الفاتورة (أو كذا فاتورة مع بعض)
  ↓
اكبس  ⚙  (قائمة الإجراءات)
  ↓
اختار  «✓ علّم كمدقّقة»
```
خلص. أودو بيكتب بحاله:  `✓ مدقّقة 2026-09-16` — والتاريخ **تاريخ اليوم تلقائياً**.
والفاتورة بتختفي من «فواتير للتدقيق» وبتظهر بـ«فواتير مدقّقة».

**ما في زر «إرسال»** — الإرسال بيبعت الفاتورة للزبون بالإيميل، إشي ثاني خالص.

### للتراجع
نفس المسار → **«✗ شيل علامة التدقيق»**.

### 🛡️ الزر بيحمي البيانات الموجودة
- فاتورة مرجعها فاضي   → `✓ مدقّقة 2026-09-16`
- فاتورة مرجعها «فاتورة ورقية سابقة رقم 0214» → `فاتورة ورقية سابقة رقم 0214 | ✓ مدقّقة 2026-09-16`
- كبست الزر مرتين بالغلط → **ما بيتكرر**، بيضل علامة وحدة

*(مجرَّب فعلياً على `INV/2026/00056` و `INV/2024/00004` — العلامة انحطت، انحفظ المرجع الأصلي، والتراجع رجّع كل إشي زي ما كان.)*

## ٢) الطريقة اليدوية (لو بدك تكتب ملاحظة)

الحقل **مش بأعلى الفاتورة**. بفاتورة العميل هو جوّا:
```
افتح الفاتورة → تبويب «معلومات أخرى» → مجموعة «الفاتورة» → «رقم العميل المرجعي»
```
اكتب `✓ مدقّقة 2026-09-16 · ملاحظتك` واحفظ (☁).
**لو الحقل فيه إشي، ما تمسحه** — ضيف بعده ` | ` وبعدين العلامة.

## ٣) طرق تأكد إضافية

**المفضّلة (★)** بشريط البحث — فيها فلترين محفوظين:
`✓ فواتير مدقّقة` · `⏳ فواتير لسا ما اندققت` — الاتنين **مجمّعين حسب المشروع**.

**البحث المباشر**: اكبس 🔍 واكتب `مدقّقة` → اختار **«البحث في الرقم المرجعي»**.

---

## ⚠️ ملاحظات
- العلامة لازم تحتوي كلمة **مدقّقة** بنفس الإملاء (قاف + همزة على الياء) عشان الفلاتر والقوائم تلقطها.
- التاريخ مش إجباري بس بينفع للمراجعة بعدين.
- للتراجع: امسح النص من الحقل واحفظ.
- القوائم والفلاتر **سجلات بيانات مش كود** — العدّاد ضل `{'version': 1}` بعد إضافتهم (اتأكدت بتشغيل فحص أودو نفسه).
